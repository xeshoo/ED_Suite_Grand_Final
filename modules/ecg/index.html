Deploying to GitHub Pages

  1. Create a new repository (or reuse an existing one) on GitHub.
  2. Upload this file, keeping the name index.html (or add it alongside your other tools and link to it).
  3. Go to Settings → Pages, set source to your main branch, root folder.
  4. Your tool will be live at https://yourusername.github.io/reponame/ within a minute or two.
